# Kotla Medicals Premium Website

## Goal
Create a completely original, colorful, premium, animation-led pharmacy website. The existing Kotla Medicals website will supply facts and selected imagery only; none of its visual design or page structure will be copied.

## Build
- Establish a new healthcare design system using electric blue, cyan, aqua, mint, fresh green, controlled purple and pink accents, white, and deep navy.
- Use Space Grotesk headings with DM Sans body text, responsive sizing, strong contrast, and reduced-motion support.
- Build an immersive first screen with layered source imagery, animated medical details, real call and directions actions, and a floating glass navigation.
- Add distinct sections for trust signals, an asymmetric business story, real services, swipeable product/category highlights when source-supported, a creative why-us composition, a dark heartbeat interlude, and a stylized location/contact area.
- Add lightweight CSS/SVG motion, scroll reveals, mobile navigation, touch-friendly floating actions, and tasteful glass treatments without a heavy animation library.
- Centralize verified business facts and selected image references so content is not duplicated.

## Content and assets
- Verify the business name, description, services, address, phone, hours, links, and available source images from the existing website.
- Use only verified claims and omit unsupported statistics, products, pricing, inventory, WhatsApp, or coordinates.
- Download only the source images needed for this design, optimize them locally, and provide meaningful alt text.

## Quality and delivery
- Add route-specific SEO and social metadata, LocalBusiness structured data, canonical details when verifiable, and accessible semantic markup.
- Keep the experience fast through local optimized images, lazy loading below the fold, reusable sections, CSS/SVG animation, and no large video or 3D assets.
- Validate the complete page on desktop and mobile, test the main call/directions/menu interactions, and resolve preview, console, and broken-link errors.
